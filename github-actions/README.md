# GitHub Actions – CI/CD Labs

Practical GitHub Actions labs focused on CI/CD,
Terraform automation and Azure deployments.

## Learning Goals

- Understand workflows, triggers, jobs and steps
- Run workflows on GitHub-hosted runners
- Validate Terraform automatically
- Use Pull Requests for infrastructure changes
- Authenticate to Azure using OIDC
- Implement controlled Terraform deployments

## Labs

1. First GitHub Actions Workflow
2. Terraform CI Pipeline
3. Pull Request Validation
4. Azure Authentication with OIDC
5. Terraform Plan and Apply
6. Enterprise CI/CD Practices
