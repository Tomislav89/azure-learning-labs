# Azure Learning Labs

A structured collection of hands-on labs, technical notes, experiments, and interview preparation material created while developing practical Azure and DevOps engineering skills.

The repository focuses on understanding how Azure services work in practice rather than only preparing for certification exams.

## Objectives

The main objectives of this repository are to:

- Build practical Azure administration skills.
- Prepare for the AZ-104 and AZ-400 certifications.
- Practice Azure CLI and Infrastructure as Code.
- Document Azure architecture concepts and operational knowledge.
- Explore enterprise Azure patterns and best practices.
- Practice troubleshooting and technical interview scenarios.

## Learning Approach

Topics are studied using the following workflow:

1. Study the core concept.
2. Understand the underlying Azure architecture.
3. Explore the service through the Azure Portal.
4. Practice Azure CLI where applicable.
5. Implement the solution using Terraform where applicable.
6. Complete hands-on labs.
7. Document important findings and troubleshooting notes.
8. Review the topic through technical interview questions.

## AZ-104

The AZ-104 section covers Azure administration and platform fundamentals, including:

- Azure infrastructure and resource organization
- Identity and access management
- Storage
- Compute
- Networking
- Monitoring
- Backup and disaster recovery
- Governance
- Automation

## AZ-400

The AZ-400 section will focus on DevOps engineering practices, including:

- Source control
- CI/CD
- Infrastructure as Code
- Deployment strategies
- Security
- Monitoring
- Azure DevOps and GitHub workflows
